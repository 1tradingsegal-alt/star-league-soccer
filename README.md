# ⚽ Star League Soccer

بازی فوتبال سریع و آرکید برای اندروید: حالت حرفه‌ای (ساخت باشگاه، خرید ستاره‌ها، ارتقای ورزشگاه)، بازی دوستانه، لیگ‌های جهان، آب‌وهوا و داورهای مختلف. کاملاً آفلاین.

## دانلود APK
به بخش **Releases** همین ریپازیتوری بروید و آخرین فایل `StarLeagueSoccer.apk` را دانلود کنید.
روی گوشی، نصب از «منابع ناشناس» را برای مرورگر یا برنامهٔ فایل‌ها مجاز کنید.

## ساخت خودکار
هر بار که چیزی به شاخهٔ `main` پوش شود، GitHub Actions اپ را با Capacitor می‌سازد و یک Release جدید با فایل APK منتشر می‌کند.

## ساختار
- `www/index.html` — کل بازی (HTML5 Canvas)
- `capacitor.config.json` — تنظیمات اپ اندروید
- `.github/workflows/android.yml` — ساخت APK
